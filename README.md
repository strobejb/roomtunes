# Room Tunes

[![Build and Test](https://github.com/strobejb/roomtunes/actions/workflows/build.yml/badge.svg)](https://github.com/strobejb/roomtunes/actions/workflows/build.yml)
[![Release](https://github.com/strobejb/roomtunes/actions/workflows/release.yml/badge.svg)](https://github.com/strobejb/roomtunes/actions/workflows/release.yml)

Desktop Sonos controller for Windows and Linux, built with Qt6. An evolution of the original RoomTunes for BlackBerry 10.

Read more at: https://www.catch22.net/blog/2026-08-11-roomtunes/

* Android support will arrive soon
* MacOS support is intended but currently experimental and untested by the maintainer.
